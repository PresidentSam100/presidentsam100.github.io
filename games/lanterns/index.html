灯 Lanterns

the pinyin typing festival

Paper lanterns rise with a word in hanzi — type its pinyin to light it before it drifts away. Each letter narrows it down, and a full match lights the most urgent one — if a longer word up there still fits (ni, with nian rising), it waits a beat, or Space lights it now. Backspace steps back. Type V for ü (旅 = lv). Three lost lanterns end the night.
